# Thesis-Appendix
This repository contains the data files produced for Master's Thesis "AI Demand Paradox and Macroeconomic Feedback Loop". 

"AIOE Scores by Occupation" excel file has been obtained from the following work: 
Felten E, Raj M, Seamans R (2021) Occupational, industry, and geographic exposure to artificial intelligence: A novel dataset and its potential uses. Strategic Management Journal 42(12):2195–2217.

Below is a list of data posted on this page:
Appendix A. AIOE Scores by Occupation, extended with data from US BLS Occupational Employment and Wage Statistics, and Employment projections data 2024-2034. 
Appendix B. BLS declining occupations, cleaned up by assumed AI-driven occupations.
Appendix C. BLS growing occupations, cleaned up by assumed AI-driven occupations.

The files within the input folder contain the code for calculations and plots.
